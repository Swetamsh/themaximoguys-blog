# Archived 2026-08-13 — unlabeled first-generation covers

These are the original MAS 9.2 series covers, generated 2026-08-12 in the approved
warm-chalkboard style (espresso ground, bone chalk linework, people thinking).

**Why archived:** the style was right but the boards carried no information. To avoid
hallucinated/misspelled words, the generation prompts banned all text except the post
title — so every board panel came out filled with squiggle placeholder marks, tally
strokes and generic icons. The concepts were unreadable. Cover 02 is titled "Three
Versions, One Table" and its three columns held scribbles where 9.0 / 9.1 / 9.2 belong.

**Replaced by:** same filenames in the parent directory, regenerated with explicit
closed-list labels drawn from each post's own headings and tables.

Kept for reference — the illustration quality and composition of these is still good.
