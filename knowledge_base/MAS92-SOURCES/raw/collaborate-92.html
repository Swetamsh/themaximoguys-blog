What's new in Maximo Collaborate 9.2

Learn more about what's new and changed in Maximo® Collaborate.

IBM® Maximo Collaborate an add-on in Maximo Manage

Maximo Collaborate is now an add-on in Maximo Manage.

As part of this enhancement, Expert Groups and Technicians applications are migrated to Person Groups and Labor applications in Maximo Manage. For more information, see Person groups and Labor application.

For configuring Interactive Connectivity Establishment (ICE) servers, Collaborate app settings are now part of the Mobile Configuration application in Maximo Manage. For more information, see Configuring Collaborate application settings.

Restriction: Maximo Collaborate cannot be installed on Single Node Red Hat® OpenShift® (SNO) environments.
For more information, see Getting started.
Collaboration sessions available in Maximo Manage

The Collaborate Sessions application is now available in Maximo Manage as the Collab Session application under Work Orders. You can search, filter, and view collaboration sessions, including associated work orders, assets, and participants in the application.

You can also download session summary PDFs after a session is completed, providing a centralized way to review collaboration activity across technicians and remote experts.

For more information, see Collab Session application in Maximo Manage.

Enhanced collaboration options for technicians in IBM Maximo Mobile
Technicians can now collaborate with remote experts without starting a video or voice call by initiating a collaborate request by using Contact expert option in Collaborate application or Get assistance option in a Work order. Technicians can choose how a collaboration request is handled, either through a video or audio session or as a chat‑only interaction.

These options are now available across Maximo Mobile, giving users easier access to real‑time support. When a remote expert accepts a collaboration request, they can immediately see whether the session is video, audio, or chat only, ensuring a smoother and more efficient hand-off.
