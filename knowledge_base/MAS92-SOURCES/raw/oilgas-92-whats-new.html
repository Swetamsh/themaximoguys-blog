Emissions and compliance management

Waste management application
The new Waste management application helps environmental officers, supervisors, or managers track waste from generation through storage, handling, and final disposal. Use it to manage waste storage, monitor waste amounts by location, report waste production, and meet regulatory compliance requirements.

The Waste management application connects seamlessly with your broader environmental workflows, linking waste data with inspections, risk assessments, regulations, and certifications.

For more information, see Waste management.

Companies application for regulatory compliance
The new Companies application in the Safety module can be used to manage safety‑related information for contractors, vendors, and other companies. The application supports the organization and maintenance of company safety data to help ensure consistent implementation of safety processes and compliance requirements.

For more information, see Companies application.

Predefined domains in Locations
You can now select values for Subunit/Component Code and Maintainable Item/Part Code from predefined domains in the Locations application, under the Failure Analysis tab.

Previously, these were open text fields in Locations application, which might lead to inconsistent data entry. With this update, the same domains that are used in Work Order Tracking are now applied, so that you can choose standardized values.

No additional configuration is required to use this capability.

Automatic Carbon Dioxide equivalent (CO₂e) calculation for fugitive emissions
You can now automatically calculate carbon dioxide equivalent (CO₂e) values for fugitive emissions by using the Envizi greenhouse gas (GHG) API.

In the Incident events table, a new Emission gas type field is available. Select a gas type and enter the emission amount and unit of measure. When you save the record, Maximo Manage sends the emission details to Envizi, which calculates the CO₂e value and returns the result. The CO₂e amount and CO₂e unit of measure fields are automatically populated.

This capability removes the need to perform emission calculations manually or by using external tools.

For more information, see Envizi GHG API integration for emission calculations.

Related records management

AI-powered incident categorization
Use artificial intelligence to automatically categorize incidents in the Tickets application. The multi-class classifier (MCC) model analyzes incident summaries and details to suggest appropriate values for the Incident Type and Incident Category fields.

The MCC model is trained on your organization's historical incident data to learn patterns and relationships between incident descriptions and their categories. When you enter text in the Summary or Details field, the model provides multiple suggestions ranked by confidence level. You can review the suggestions and manually select the one that best describes the incident.

AI-powered incident categorization helps reduce manual effort in categorizing high-frequency, low-consequence incidents, improves consistency in incident classification, and enables better analysis of incident trends for preventive action.

For more information, see AI-powered incident categorization.

Improved inspection assignments
You can now assign inspections to specific individuals or groups to reduce unnecessary downloads of unassigned inspections to mobile devices. New fields in the inspection results identify the assigned owner and owner group for each inspection. Applications use this information to route inspections to the appropriate personnel.
The following applications now support the updated inspection assignment process:
  • Access Permits
  • Audit and Surveys
  • Incidents
  • Operator Rounds in Operator Log
  • Risk Assessments
  • Management of Change (MOC)
  • Waste management

These applications also include a new Related Inspections section under the Related Records tab, providing quick access to inspections associated with each record. Inspections can be completed using the Inspections application or IBM Maximo Mobile Inspections app on supported mobile devices.

For more information, see Assigning inspections and Related inspections for a record.

Integration with IBM Maximo Mobile

Field based permit approvals
The new Permit to work mobile application is integrated with existing Maximo Oil & Gas to help ensure that mobile-created permits align with industry-established safety processes, approval, validation, and control mechanisms. It enables technicians to initiate Permit to work requests directly at the job site so that permit data is captured accurately and promptly in industrial and safety-sensitive environments.

For more information, see Managing work processes with permit to work.

Maps in Incident reporter
To streamline the incident reporting process and enable faster resolution of incidents, preview existing incident details from a map or add a new incident associated to an asset or location from the map.

For more information, see Incident reporter.
