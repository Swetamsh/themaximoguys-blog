What's new in Maximo IT Version 9.2

Edit online

IBM Maximo IT 9.2 continues to expand its vision of managing not just IT assets, but the broader portfolio of IT and OT services delivered to the business. This release strengthens Maximo IT’s role as a unified platform for service-centric asset management, helping organizations connect assets, configuration items, services, and operational outcomes.

With an increased focus on service delivery, visibility, and automation, Maximo IT 9.2 enables IT and OT teams to operate more efficiently while delivering greater business value. This release introduces new capabilities that enhance how IT/OT services are defined, managed, and consumed. The Software Tracking application updates software lifecycle governance with a focus on how software is cloud based more than ever before, ensuring compliance and visibility across service dependencies. Offerings Creation simplifies how service catalog offerings are designed and published, accelerating the rollout of IT and OT services to end users. Enhancements such as Service Bundling improve the self-service experience, while the Services View application gets a new Reliability tab providing deeper insights into service performance and operational health. In addition, integration with IBM MaaS360 strengthens device and asset visibility, supporting more connected and responsive service workflows. Together, these advancements position Maximo IT 9.2 as a comprehensive platform for managing IT and OT services in alignment with business needs.

New and enhanced applications

Agentic AI assisted incident summarization and knowledge creation (solution generation)

Maximo IT now enhances AI-driven assistance by summarising incidents as and when any action is taken on it. Another use case is automatically generating solution content from incident work logs once an incident reaches the Resolved state.

With this enhancement:

  • The AI agent will provide a detailed summarization of open incidents and suggested resolution when prompted.

  • A watson Orchestrate AI agent runs in the background to analyze incident work log entries and generate a solution record in Maximo IT.

  • Service agents can review and publish the generated solution.

  • When an incident is marked as resolved, the AI agent generates a solution record to support knowledge reuse and faster future resolutions.

This capability helps improve solution quality, reduces manual documentation effort, and accelerates knowledge creation across service teams.

For more information, see Agentic AI enablement in Maximo IT using watsonx Orchestrate.

Efficient software tracking with the Software Tracking application

Track and manage software licenses with greater clarity and control. Organizations can now maintain better oversight of software usage and compliance. The Software Tracking application provides an intuitive interface for tracking software licenses, enabling software allocations, and maintaining accurate records of software entitlements. This capability helps organizations optimize software usage, reduce compliance risks, and improve visibility into their software portfolio.

For more information, see Software Tracking.

Simplifying Offering creation with the Service Offerings application

This new application removes the need for offerings to be created by only administrators. Now, any user can design and publish service offerings more efficiently with a dedicated interface for creating and managing service catalog offerings. Extending the reach of offerings to allow for HR, Legal, Finance, IT, OT or really any part of the business which desires an offering for requesting from users. Service Offering application enables users to create and configure service offerings that can be requested through Self Serve. This application extends offerings to well beyond IT and simplifies the process of defining services, improving service catalog management and accelerating the rollout of new offerings.

For more information, see Service offerings.

Enhancements

Submit multiple services with Service bundling in Self Serve

Improve request efficiency by allowing users to submit multiple service requests in a single transaction. With service bundling, users can select and submit multiple services together within a single request in the Self Serve application. This capability simplifies request management, reduces repetitive submissions, eases the focus for approvals, and improves the overall user experience when requesting related services.

For more information, see Bundling service requests.

Improved collaboration with sound notifications for chats originating from Self Serve Application

Stay informed of ongoing conversations with sound chat notifications. Self Serve now supports sound notifications for chat messages, helping service desk analysts and users stay aware of incoming messages during multiple active conversations. This enhancement improves responsiveness and ensures messages are not missed.

For more information, see Chats in Self Serve.

Focused navigation with the left navigation panel

Access applications more efficiently with the focused left navigation panel.

Maximo IT includes support for the focused left navigation experience, which simplifies application access by reducing navigation nesting and displaying applications directly in the left navigation panel. Users can personalize their navigation experience by selecting the applications that they want to display, and their preferences are saved. Application visibility continues to respect Security Group access, ensuring that users only see applications that they are authorized to use.

This enhancement helps users quickly access frequently used applications and improves overall navigation efficiency across Maximo IT.

For more information, see Personalizing the side navigation menu.

Gain deeper insights with the new Reliability tab and information in Service View application

View service performance and operational data directly within the Service View application.

The Reliability tab in the Service View application provides enhanced visibility into service-related information and metrics, enabling service teams to quickly assess performance indicators and gain better understanding of operational health. This improvement helps teams make informed decisions, return services to promotion state, and better understand service behaviour.

For more information, see Service reliability metrics.

IT-OT Service support across ITSM applications

Maximo IT extends Service View integration to the Change, Problem, Solution, and Release applications. The existing Service field is updated to support IT-OT Service selection, enabling improved service association and visibility across ITSM processes. This enhancement is also available in Self Serve, where end users can now report issues against an IT-OT Service. The update helps improve operational context and service tracking across IT and OT environments.

Automatic visibility of the IT Details tab in Assets

Maximo IT improves the user experience in the Assets application by automatically displaying the IT Details tab when Maximo IT is installed in the suite. This enhancement reduces configuration complexity, eliminates dependency on manual classification setup, and ensures that IT asset details are immediately available to users out of the box. Organizations can still customize or hide the tab by using Application Designer, if required.

For more information, see Managing IT assets.

Expanded Service Delivery scope to include service requests

The Service Delivery application now supports Service Request (SR) records in addition to Incidents.

With this enhancement, service agents and managers can now view, prioritize, and manage both Incidents and Service Requests within a single, unified workspace. This expanded scope improves workload visibility, reduces application switching, and enables more consistent handling of service-related work across teams.

For more information, see Service Delivery.

Create incidents and service requests directly from Service Delivery

Service agents can now create Incident and Service Request records directly from the Service Delivery application. With this update, agents can initiate new Incidents or Service Requests and take ownership of them without leaving the Service Delivery workspace. This enhancement simplifies service intake, reduces context switching, and improves overall agent productivity.

For more information, see Creating incidents and service requests.

Expanded integrations

Discover assets with IBM MaaS360 integration

Enhance asset visibility and device discovery across enterprise environments.

IBM Maximo IT now integrates with IBM MaaS360 to support automated asset discovery and synchronization of managed devices. This integration enables organizations to import device information into Maximo IT, improving asset visibility and strengthening service management workflows.

For more information, see Integrating with IBM MaaS360.

Deprecations

Self Service Center deprecation

The Self Service Center application is deprecated in Maximo IT Version 9.2. Organizations are encouraged to transition to the Self Serve application, which provides an improved and modernized self-service experience for submitting and managing service requests.

Platform updates

Future-ready platform with Java 25 support

Maximo IT Version 9.2 now supports Java 25, ensuring improved platform performance, stronger security, and continued alignment with modern enterprise technology standards. The updated Java support enables organizations to benefit from improved JVM optimizations, enhanced security capabilities, and long-term platform stability.
