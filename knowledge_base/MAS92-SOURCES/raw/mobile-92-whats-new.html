Notification and navigation panel enhancements
The notification panel in Maximo Mobile is enhanced to improve usability and clarity.
  • Navigation controls let you open the related Maximo Mobile app or deep‑linked action directly from any notification.
  • Notification is expected not to be received when token for the notification has expired per user and device.
  • Improved management options in notifications panel allows you to delete notifications individually or in bulk, and mark all as read or unread. Note that the deletion actions are permanent.
  • In notification panel updated sorting order and visually display unread notifications with a blue background and position them above read ones.
  • Case‑insensitive search helps you filter notifications while preserving the existing sort order.
  • Long descriptions now show an ellipsis and when you select the notification, the text displays the full description as a tooltip.
  • A sound is heard when a notification is received when the application is closed or minimized.
  • Accurate badge counts update automatically after read or unread changes, deletions, or when a notification is opened.
  • The Maximo Mobile icon badge shows the number of new unread notification messages on supported devices. Only on Google Android devices, a notification dot also appears on the badge to indicate unread notifications.
Configure preloaded databases
Configure preloaded databases in the Mobile Configuration application of Maximo Manage. You can view the status and disable or delete the preloaded databases. For more information see Configuring preloaded databases.
Configurable image upload compression
Maximo Mobile now includes configurable image compression to help optimize network usage and synchronization performance.

Administrators can control how image attachments are handled before upload from mobile devices:

  • Enable or disable image compression for mobile image attachments.
  • Set a default upload quality that is applied when users attach images.
  • Allow user override so mobile users can choose to upload a full‑resolution image when required.

By configuring these options, administrators can reduce network data consumption and synchronization times while still supporting business scenarios that require high‑resolution images. For more information, see Configuring image upload quality.

Manually stop preloaded database generation

In the Mobile Configuration app, select the preloaded database for which you want to stop the generation, click the overflow menu and select Stop generation. The database generation is stopped and cannot be resumed. A new database generation starts according to the schedule defined in the mobiledbCrontask cron task.
Optimize data downloads for faster login
You can now configure parallel data downloads to reduce login time. Maximo Mobile downloads configuration data, system information, and images at the same time. This speeds up the login process. Maximo Mobile also consolidates module update checks into a single request. This reduces network traffic and improves performance. For more information, see Optimizing data downloads for faster login.

Technicians and crew supervisors can now view, accept, execute, and complete work orders assigned to crews. Any crew member or supervisor can start or stop travel and work timers on behalf of the crew, automatically creating labor transactions for all active crew members. Labor can be reported for the entire crew or for individual members, with flexibility to edit or delete entries. When a crew work order is completed, all active labor transactions are automatically closed. The crew functionality is controlled by a security option, allowing administrators to enable or disable the feature based on organizational requirements.
Timesheets app for labor reporting
Technicians can now view their labor hours in a time-based format through the new Timesheets app. The app displays labor entries for today or yesterday, showing work order details, asset and location information, transaction types, and total hours reported. Each labor entry can be expanded to view detailed information including duration, premium pay codes, and task details. The Timesheets app provides a read-only view of labor transactions and always fetches the latest information from the server to ensure accuracy.

Calibration enhancements for technicians

Indicate completion of environmental conditions on the Asset function page in Maximo Mobile app
As a field technician, you can enter values for environmental conditions, tap Save, and the saved entries are visually indicated by a green tick on the Asset functions page. User-entered values are validated and any errors are handled offline.
Ability to view uncertainty fields
As a calibration technician, you can now view calibration uncertainty fields in the Maximo Mobile app at the data sheet level or asset function level while executing a calibration work order.
Enhancements to failure reporting
As a calibration technician, you can now specify whether an instrument was used after its calibration expiration, immediate action taken, and whether the instrument is ready to use after correction.
Indicate when an asset or location associated with a work order requires calibration
As a calibration technician, you can now see the calibration icon when an asset or location is selected in a work order, and the work type is set to a synonym of CAL.

The calibration icon appears in the system when certain configuration or data conditions are met. It helps calibration technicians to quickly identify records that are related to calibration activities.

The calibration icon is displayed when any of the following conditions are met:
Calibration work type selected
The calibration icon is visible if the asset or location is not calibrated, and a work type is selected for which the WORKTYPE synonym domain max value is CAL.
Calibration work types are defined in the system configuration and must meet the following criteria:
  • In the WORKTYPE synonym domain the max value is set to CAL.
  • In the Organization Settings application, navigate to the relevant site, for example, EAGLENA. Go to Work Order Options > Work Type and view the list of available work types or create a work type.
  • When creating a work type for calibration, set the WORKTYPE.TYPE to CAL
Once configured, the work types appear in the Work Type field of the work order. Selecting any of these work types triggers the Calibration icon to be displayed.
Datasheet added for non-calibrated asset or location
The Calibration icon is also displayed when at least one datasheet is added. This ensures that the icon is visible when calibration-related datasheets are associated with the record, even if the work type is not defined as calibration.
Functional check and dynamic check statuses
For a calibration work order, when the functional check status is set to manual, you can see a list of statuses at the data sheet level and at the asset function in Maximo Manage. The statuses are:
  • ACTION
  • ADJREQD
  • ADJTOIMP
  • BROKEN
  • FAIL
  • INSPECT
  • LIMITED USE
  • MISSING
However, the possibility of the statuses is only PASS and FAIL. Therefore, when you do a manual selection, it does not save the work order. It considers the calculated status only and you cannot do a manual selection in the Maximo Mobile app.
Remove rotating tools from completed or closed work orders
Technicians can now remove tool transactions from calibration work orders for all the statuses except WAPR (for example, CAL, and other synonym domains) after they have been completed or closed, if the organization is configured to allow this capability. This provides flexibility to correct tool assignments even after work order completion.
Note: Technicians can only view closed work orders that are related to current assignments in the Technician app by selecting Work order history option from the dropdown menu.
Calibration accuracy validation
Technicians can now validate calibration standard accuracy when adding tools to work orders. When you select a rotating asset as a calibration standard, Maximo Mobile automatically compares accuracy specifications and displays error or warning messages if the standard's accuracy is lower than the asset under calibration. This ensures regulatory compliance and prevents the use of inadequate calibration standards in the field.
You can now skip the accuracy check for specific assets in special cases. Select the Bypass Accuracy Validation checkbox on either asset. Maximo Mobile then skips the check and lets you continue. Use this option for older equipment, emergency situations, or non-standard equipment.
Remove rotating tools from completed or closed work orders
Technicians can now remove tool transactions from calibration work orders (for example, CAL, EMCAL, or PMCAL, and so on) after they have been completed or closed, if the organization is configured to allow this capability. This provides flexibility to correct tool assignments even after work order completion.
Note: Technicians can only view closed work orders that are related to current assignments in the Technician app by selecting Work order history option from the dropdown menu.
Optional calibration support for technicians
Administrators can now control calibration functionality in Maximo Mobile with the maximo.mobile.technician.enablecalibration system property. When calibration is disabled, calibration-related fields and data are hidden from technicians, which can reduce mobile data download and synchronization time. When calibration is enabled, the existing calibration functionality remains available. By default, the maximo.mobile.technician.enablecalibration system property is disabled.
Note: Once an admin changes the maximo.mobile.technician.enablecalibration system property value, technicians must re-login and reload all data in the Maximo Mobile app.

Enhancements for developers

Optimize doclinks for faster mobile downloads
You can now customize doclinks relationships to improve mobile download performance. Maximo Mobile and Maximo Manage use separate relationships for mobile apps and browser access. The MOBILE_DOCLINKS relationship has a simplified query that downloads data faster to mobile devices. The MANAGE_DOCLINKS relationship handles browser access. You can customize each relationship independently without affecting the other. This reduces download time and improves app performance for mobile users.

Inspection Forms enhancements for technicians

Scan responses in Inspection Forms

You can now use QR, NFC, or barcode scanning to populate responses for text and numeric questions in inspection forms. Form designers can enable scanning for individual response fields to reduce manual entry errors and improve efficiency.

A new scan-only response type is also available. Use this option when responses must be captured through scanning and cannot be edited manually. You can configure these fields as required, control their visibility, and ensure that inspections cannot be completed without scanning where needed.

Calculated responses in Inspection Forms

You can now add calculated response fields to inspection forms. Use formulas to automatically compute values based on other responses in the form.

Calculated fields are read-only and update automatically when all required inputs are provided, reducing manual calculations and data entry errors.

Form and question instructions in Inspection Forms

You can now display instructions directly in the inspection. Enable form-level instructions to show guidance before an inspection starts or within the form.

Display question and group instructions inline with each question. Expand to view full details. Attachments are available in the instructions for additional context.

Geolocation responses in Inspection Forms

You can now capture geolocation data as part of inspection responses. Use a geolocation response type to record GPS coordinates directly within a form.

Technicians can capture their current location with a single action, or use an interactive map to select and record specific locations. When using the map, you can record points, lines, or polygons to document precise locations during inspections.

Record comments during inspections

You can now add comments during an inspection without creating a separate question. Access the option from the action menu to capture comments as part of the response.

This reduces form complexity and avoids adding extra fields while still supporting comment capture when needed.

Add inspections from Work Order Details

You can now create and manage inspection forms directly from the Work Order Details page. This enhancement streamlines technician workflows by reducing navigation steps and enabling faster inspection handling.

Technicians can initiate inspection creation, fill and save inspection forms, and associate inspection results with the work order without leaving the Work Order Details page. The feature ensures proper form persistence, correct navigation after saving, and consistent behavior when reopening saved inspections across both online and mobile environments.

Add descriptions and names to file attachments in Inspection Forms

You can now add descriptions to file upload fields when creating inspection forms. This allows administrators to provide instructions or guidance for inspectors about what files to upload.

When uploading files in inspection forms, both administrators and inspectors can now add custom names and descriptions for each file attachment. This improves file organization and makes it easier to identify and understand the purpose of uploaded files during inspections.

Configure Inspection Forms at Site level as well as Organization level

Inspection forms can now be configured at the Site level in addition to the Organization level, similar to Job Plan functionality. The Organization and Site fields are editable when creating new forms and become part of the primary key, allowing the same form ID to be used across different sites. Forms can be defined at system, organization, or site level, and form selection in target applications (Assets, Locations, Job Plans, Routes, and Work Order Tracking) is automatically filtered based on site context.

Forms created before the upgrade will be considered ORG only and existing siteid information will be stored in the OLDSITEID attribute and cleared from SITEID. For upgrade information and details about how existing inspection forms are handled during the upgrade process, see Upgrading inspection forms to support site-level configuration.

Use the Related records option on Asset or Locations details page to see records that are associated with a particular asset or location, in one place. From this page, you can launch the corresponding applications such as Assets if in Locations page or Locations if in Assets page, Work Orders, and Inspections to work on the selected record, or create new records as needed.

A new create action is available on the Related records page. When selected, the mobile app shows the record types that are configured in Maximo Mobile. Using this action, technicians and asset managers can quickly create any supported record type that is associated with the asset or location.
