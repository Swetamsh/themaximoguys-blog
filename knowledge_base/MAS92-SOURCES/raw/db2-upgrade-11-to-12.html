Upgrading Db2 from version 11 to 12

Starting in Maximo® Application Suite 9.2, Db2® 12 is supported. You can upgrade your IBM® Db2 instance from 11 to 12 by using either the CLI or Ansible automation. Both methods require the same variables and produce the same result.

Upgrading from Db2 11 to 12 requires explicit opt-in activation and a valid IBM Db2 Warehouse license file.
Important: Without a valid license, Db2 12 operates under a 30-day trial license that causes production system outages after expiration.
  • Upgrading Db2 from version 11 to 12 by using the CLI
    Upgrade your IBM Db2 instance from 11 to 12 by using the mas update command. This major version upgrade requires explicit opt-in activation and a valid IBM Db2 Warehouse license file.
  • Upgrading Db2 from version 11 to 12 by using Ansible
    Upgrade your IBM Db2 instance from 11 to 12 by using Ansible automation. This major version upgrade requires explicit opt-in activation and a valid IBM Db2 Warehouse license file.
