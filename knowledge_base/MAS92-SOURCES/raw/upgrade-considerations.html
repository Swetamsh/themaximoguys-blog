Upgrade checklists

Before upgrading, review the key considerations that can affect your environment, timeline, and outcomes.

  • Upgrading user authentication changes from Maximo Application Suite 9.1 to 9.2
    When you upgrade from Maximo® Application Suite 9.1 to 9.2, the system automatically migrates this required data by running a pre upgrade process. The pre-upgrade process uses a datamodel-migration job to updates authentication mappings and synchronizes required SCIM fields, including externalId, so that users can continue to sign in.
  • Upgrading Db2 from version 11 to 12
    Starting in Maximo Application Suite 9.2, Db2® 12 is supported. You can upgrade your IBM® Db2 instance from 11 to 12 by using either the CLI or Ansible automation. Both methods require the same variables and produce the same result.

    Use this checklist to plan and prepare to upgrade from one version of Maximo Manage to the next version.
