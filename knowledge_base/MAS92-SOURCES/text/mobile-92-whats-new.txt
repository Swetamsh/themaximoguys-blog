Stop in progress record synchronization
You can now stop an active record synchronization in Maximo Mobile. When synchronization begins on pages that use card groups, an
inline notification displays a Stop button. You can cancel the sync at any
time. For example, if the process is taking longer than expected because of network conditions or if
you need to update data before synchronization.Records and pages that were already downloaded
remain available, and you can restart synchronization whenever you need to.
Note that, in this
release, stop‑sync support is available only for card group components. The underlying API is
available for application teams to implement in other areas.

server. The app persistently indicates the disconnected state so you always know that you are
working with local data when you do not have internet access, a VPN issue, or a server outage. Any
work that you do while disconnected is saved on your device and automatically synchronized when
connectivity is restored. You are also guided to reconnect so that you know that your updates are
synced at the right time.

Deep link enhancements
Deep linking capabilities in Maximo Mobile are enhanced to
improve usability and integration with enterprise workflows.
Generate and share deep links directly from any record view using native device sharing
capabilities such as email, SMS, or messaging apps.
Use business identifiers such as asset number and site ID in deep links instead of internal IDs
for easier sharing and integration.
When you open a deep link for a record that is not available locally, the app performs a
server-side search if you are online and downloads the record automatically.
Pre-fill fields on edit or create pages by including attribute parameters in deep links, such as
asset number, location, or description.
If multiple records match the business identifiers in a deep link, select the correct record
from a list.
These enhancements make it easier to share specific records and actions with team members,
integrate with external systems, and streamline workflows across Maximo Mobile applications. For information about configuring deep link
notifications, see Creating deep links for Maximo Mobile and Provisioning default notifications for deep link.
Crew work order management
Technicians and crew supervisors can now view, accept, execute, and complete work orders assigned to crews. A dedicated schedule list displays crew-assigned work orders separately from individual assignments. Any crew member or supervisor can start or stop travel and work timers on behalf of the crew, automatically creating labor transactions for all active crew members. Labor can be reported for the entire crew or for individual members, with flexibility to edit or delete entries. When a crew work order is completed, all active labor transactions are automatically closed. The crew functionality is controlled by a security option, allowing administrators to enable or disable the feature based on organizational requirements.
Timesheets app for labor reporting
Technicians can now view their labor hours in a time-based format through the new Timesheets
app. The app displays labor entries for today or yesterday, showing work order details, asset and
location information, transaction types, and total hours reported. Each labor entry can be expanded
to view detailed information including duration, premium pay codes, and task details. The Timesheets
app provides a read-only view of labor transactions and always fetches the latest information from
the server to ensure accuracy.
Inspection form status changes to "Completed" when the form is completed in offline mode
If an inspection form is completed in the offline mode, the status of the form changes to
completed without the requirement of the device having to come back online.
Scan an asset tag to filter and select from a list of rotating assets
In a work order, when selecting rotating materials or tools, a new scanner icon can be used to
scan the barcode of a rotating item or tool to filter out values.
Enter a failure report before saving a work order as closed or completed.
As a field technician, when you try to save a work order with the status "Closed" or
"Completed", a message prompts you to enter a failure report first. If you mark the asset status as
"Down", again a message prompts you to enter a failure report.
Add tasks, edit tasks, sort and filter task list, update observations, and create follow-up work
orders
As a field technician, you can add tasks, edit existing tasks, update observations, and create
follow-up work orders for a work order. You can also filter and sort the task list. Filters include
status, asset, and location. Sorting options include task number, status, and task sequence.

can tap the plus icon to add a material as an actual cost. It is possible to add material

are saved as Item line type.

Actuals > Materials tab.

Technicians can now remove tool transactions from calibration work orders for all the statuses

Calibration accuracy validation
Technicians can now validate calibration standard accuracy when adding tools to work orders.
When you select a rotating asset as a calibration standard, Maximo
Mobile
automatically compares accuracy specifications and displays error or warning messages if the
standard's accuracy is lower than the asset under calibration. This ensures regulatory compliance
and prevents the use of inadequate calibration standards in the field.
You can now skip the accuracy check for specific assets in special cases. Select the
Bypass Accuracy Validation checkbox on either asset. Maximo Mobile then skips the check and lets you continue. Use this option
for older equipment, emergency situations, or non-standard equipment.

maximo.mobile.technician.enablecalibration system property value, technicians

Enhancements for developers
Optimize doclinks for faster mobile downloads
You can now customize doclinks relationships to improve mobile download performance. Maximo
Mobile and Maximo Manage use separate relationships
for mobile apps and browser access. The MOBILE_DOCLINKS relationship has a
simplified query that downloads data faster to mobile devices. The MANAGE_DOCLINKS
relationship handles browser access. You can customize each relationship independently without
affecting the other. This reduces download time and improves app performance for mobile users.
Inspection Forms enhancements for technicians
Scan responses in Inspection Forms
You can now use QR, NFC, or barcode scanning to populate responses for text and numeric questions in inspection forms. Form designers can enable scanning for individual response fields to reduce manual entry errors and improve efficiency.
A new scan-only response type is also available. Use this option when responses must be captured through scanning and cannot be edited manually. You can configure these fields as required, control their visibility, and ensure that inspections cannot be completed without scanning where needed.
Calculated responses in Inspection Forms
You can now add calculated response fields to inspection forms. Use formulas to automatically compute values based on other responses in the form.
Calculated fields are read-only and update automatically when all required inputs are provided, reducing manual calculations and data entry errors.
Form and question instructions in Inspection Forms
You can now display instructions directly in the inspection. Enable form-level instructions to show guidance before an inspection starts or within the form.
Display question and group instructions inline with each question. Expand to view full details. Attachments are available in the instructions for additional context.
Geolocation responses in Inspection Forms
You can now capture geolocation data as part of inspection responses. Use a geolocation response type to record GPS coordinates directly within a form.
Technicians can capture their current location with a single action, or use an interactive map to select and record specific locations. When using the map, you can record points, lines, or polygons to document precise locations during inspections.
Record comments during inspections
You can now add comments during an inspection without creating a separate question. Access the option from the action menu to capture comments as part of the response.
This reduces form complexity and avoids adding extra fields while still supporting comment capture when needed.
Add inspections from Work Order Details
You can now create and manage inspection forms directly from the Work Order Details page. This enhancement streamlines technician workflows by reducing navigation steps and enabling faster inspection handling.
Technicians can initiate inspection creation, fill and save inspection forms, and associate inspection results with the work order without leaving the Work Order Details page. The feature ensures proper form persistence, correct navigation after saving, and consistent behavior when reopening saved inspections across both online and mobile environments.
Add descriptions and names to file attachments in Inspection Forms
You can now add descriptions to file upload fields when creating inspection forms. This allows administrators to provide instructions or guidance for inspectors about what files to upload.
When uploading files in inspection forms, both administrators and inspectors can now add custom names and descriptions for each file attachment. This improves file organization and makes it easier to identify and understand the purpose of uploaded files during inspections.
Configure Inspection Forms at Site level as well as Organization level
Inspection forms can now be configured at the Site level in addition to the Organization level, similar to Job Plan functionality. The Organization and Site fields are editable when creating new forms and become part of the primary key, allowing the same form ID to be used across different sites. Forms can be defined at system, organization, or site level, and form selection in target applications (Assets, Locations, Job Plans, Routes, and Work Order Tracking) is automatically filtered based on site context.
Forms created before the upgrade will be considered ORG only and existing siteid information will be stored in the OLDSITEID attribute and cleared from SITEID. For upgrade information and details about how existing inspection forms are handled during the upgrade process, see Upgrading inspection forms to support site-level configuration.

Location and hierarchy management
You can now manage locations from your mobile devices, streamlining the process of tracking
maintenance tasks and understanding location relationships in the field. Create, view, and modify
locations directly from the Maximo Mobile locations app. View
location hierarchies to understand location relationships on field.Note that, to update location
hierarchies by modifying parent-child relationships, only the role-based application in Maximo Manage can be used.
Improved visibility and accuracy of location meter readings
Asset managers and technicians now have improved visibility into location‑based meter readings
captured directly from the field using Maximo Mobile.Field
technicians can view, verify, and update meter readings for locations while on site, ensuring that
meter data reflects actual field conditions. Meter readings that are entered or updated offline in
the mobile app, automatically sync with Maximo Manage when connectivity is
restored.
This enhancement helps asset managers:
Ensure accurate and timely meter data for monitoring asset performance.
Reduce manual data entry, paperwork, and rework caused by delayed or incorrect readings.
Improve operational efficiency by enabling real‑time data capture from the field.
Centralized related records for assets and locations
You can now view, create, and update related records directly from the Maximo Mobile app, enabling a centralized view of asset and location
activity. This enhancement improves asset management, reduces delays in verifying information, and
makes it easier for users to act on related maintenance data while in the field.You can access
related records from the
Location and Asset details pages. Each record type shows a count, offering an at‑a‑glance summary of
associated work.
Use the Related records option on
Asset or Locations details page to see records that are
associated with a particular asset or location, in one place. From this page, you can launch the
corresponding applications such as Assets if in
Locations page or Locations if in
Assets page, Work Orders, and
Inspections to work on the selected record, or create new records as
needed.
A new create action is available on the Related records page.
When selected, the mobile app shows the record types that are configured in Maximo Mobile. Using this action, technicians and asset managers can quickly
create any supported record type that is associated with the asset or location.
