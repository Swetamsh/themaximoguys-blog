New and enhanced applications
New Formulas application
You can now find the Formulas application in the System configuration
module in the 
Maximo Manage navigation menu. Use the Formulas
application to add object formulas and attribute formulas. For more information, see Formulas.
Planning capability added to Work Orders application
In the Work Orders application, use the Plans menu to view and manage the
following items:
Labor for work orders
Manage tasks for a work order
 For more information, see Work
orders application.
Enhanced Work Queue Manager application
As an administrator, use the Work Queue Manager application to create work queues for work
orders, purchase requests, purchase orders, incidents, and service requests. For more information,
see Creating work queues.
New Status field in the Routes application
The Routes application of 
Maximo Manage has a new
Status field, which sets the route status to draft, active, or inactive. For
more information, see Creating
routes and Viewing history.
New Qualifications field in the Job Plans application
Add qualification requirements to your job plans. When you associate a work order to a job plan,
the qualification requirements in the work order align by default with the qualification
requirements of your job plan. For more information, see Adding qualifications to job plans.
Choose the start day of the week
In the Graphical Work Week and Graphical Resource View applications, the Start Week
Day entry is no longer tied to one day. In both applications, you can now choose the
start day for the week. For more information, see Creating work lists in the Graphical Work Week application and Creating resource lists.
Tasks can be milestone tasks
In the Job Plans application, in the Job Plan Tasks window, choose a task.
Then set Is Milestone to specify whether the task is a milestone task. For
more information, see Adding tasks to job plans.
Create strategies in Reliability Strategies
In Reliability Strategies, you can access a library of asset-specific failure
details and mitigation activities. The library is developed by industry and domain experts and
contains hundreds of assets and tens of thousands of possible failures across all known operating
contexts. 
On the Custom strategies tab, you can create your strategies for your
organization's specific assets. For more information, see Creating strategies.
You can also bulk import failure mode details. For more information, see IBM Marketplace.
Deprecated applications
Work Centers
Starting in 
Maximo Manage 9.0, the Inspection Forms and
Manage Monitoring Information Work Centers are deprecated. The Inspection Forms Work Center is
replaced with a new Maximo Application Framework application that has
the same functionality. For more information, see Managing inspection forms and Manage Monitoring Information.
IBM Digital Twin Exchange
Starting from 
Maximo Manage 9.0, Digital Twin Exchange is no longer supported.
Integrations
New functions added to thetools API
You can use thetools API to check the 
Maximo Manage build status and add, update, or delete customization
archives with or without secrets. For more information, see APIs to invoke utilities and administrative functions.
Integration with Cognos® Analytics stand-alone server
You can use your own Cognos Analytics stand-alone server license and
integrate it with 
Maximo Manage. For more information, see Configuring Cognos Analytics stand-alone server.
Technical updates
Setting build tag limits
When you run different server bundles and have multiple builds, the image registry can run out
of space. You can set build tag limits to manage space and make more resources available. For more
information, see Setting build tag
limits.
Access to internal scripts
You can create your own folder to store and run script files and access internal script files in
both the tools/maximo and the tools/maximo/internal
folders by using the tools API. For more information, see APIs for
administrative utilities.
Endpoints in the KPI Manager application
In the KPI Manager application, you can specify an endpoint instead of a KPI query to obtain
data from external sources, for example, from Maximo Monitor. For more
information, see Creating
key performance indicators.
New system property for electronic signature validation
The new mxe.usemasforesig system property is implemented in the System
Properties application in 
Maximo Manage. For more information,
see Electronic signature properties.
Map support
Support is deprecated for Bing Maps and Google Maps as map providers. Support is available for
the OpenMap application. For more information, see Map Manager
Dashboard enhancements
Creating and managing dashboards
As a Maintenance Manager, you can now create personalized dashboards and manage access to these
dashboards. For more information, see Creating dashboards.
Viewing work queues on the Operational dashboard
On the Work queues card, you can view only the work queues that are
relevant to you. When you click on a work queue to open it from the Operational dashboard and then
sort or filter information, it is saved as your personalized view of the work queue list. For more
information, see Work queues.
Assign emergency work on the Dispatching dashboard
As a dispatcher, you can see emergency work orders in your schedules and assign the emergency
work orders to appropriate resources. For more information, see Assigning emergency work in the dashboard.
Graphical View is renamed and has new functions
On the Dispatching dashboard, Gantt chart is the new
name for Graphical View. The Gantt chart has the new functions to show the
status of a work order and high-level details about a work order. You can also open a map. For more
information, see Exploring the Gantt chart.
User assistance improvements
In-application tour
An in-application tour is available that guides you through adding a card to the
Operational dashboard. Click Take a tour in the
Start Center in the 
Maximo Manage user
interface to get started.
