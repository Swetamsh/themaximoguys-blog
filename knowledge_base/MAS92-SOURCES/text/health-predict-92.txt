What's new in Maximo Health 9.2 and Maximo Predict 9.2 in IBM Maximo Application Suite
What's new in Maximo Health 9.2 and Maximo Predict 9.2
Learn about what's new and changed in Maximo Health and Maximo Predict.
Prerequisite software changes
For information about prerequisite software changes, see Whats new in IBM Maximo Application Suite 9.2.
New features and enhancements
New asset health models for electrical assets
As a reliability engineer, use the new asset health models to calculate health, risk,
criticality, effective age, and end-of-life probability scores for additional electrical
transmission and distribution assets. These models help you identify and prioritize assets with the
greatest impact on grid performance and operational costs, which enables proactive maintenance
planning. For the complete list of models, see Maximo Health default notebooks and asset class notebooks.
Organized dashboard with functional tabs
As a reliability engineer, you can now navigate the Assets and locations
dashboard more efficiently by using the organized functional tabs. The dashboard groups related
metrics into dedicated Health, Strategy,
Alerts and Meters, Reliability, Asset
life, and Predict (If enabled) tabs, which reduces clutter and
streamlines access to key performance indicators. This modular structure improves decision-making by
presenting relevant data in logical groupings. For more information, see Assets & locations.
Configurable cards on the Assets and Locations dashboard
As a reliability engineer, you can now personalize the Assets and Locations
dashboard by adding, removing, and rearranging cards by dragging and dropping them. For more
information, see Configuring the dashboards.
AI-generated insights
The Insights card on the Health tab now delivers
AI-powered analysis of your asset's performance. Get visibility into key trends, potential risks,
and upcoming maintenance requirements. For more information, see Health
cards and AI-generated insights for assets.
Enhanced Assets and locations dashboard insights for reliability, cost, and observability
As a Maximo Health user, use the Assets and
Locations dashboard to analyze Failure history, track
Total maintenance cost, and gather other data points to better understand
asset performance and lifecycle cost drivers. In addition, this update delivers security
improvements that strengthen validation and overall system robustness, along with an updated design
system integration that improves compatibility and observability for more reliable monitoring and
performance insights. For more information about the Assets and locations dashboard, see Assets & locations.
New alert cards for assets and locations
As a reliability engineer, you can now view and manage open alerts for assets and locations
directly on the Alert and meters tab on the Assets and
locations dashboard. For more information, see Alerts and meters tab.
Incident history on asset or location details page
As a reliability engineer, you can now view all incidents associated with an asset or location
directly on the Alerts and meters tab of the asset or location details page.
The new Incident history section displays all incidents linked to the asset
or location, which enables you to quickly investigate incident patterns and their impact on
asset/location health scores. Clicking on an incident ID redirects you to the corresponding incident
record in the Incidents (HSE) application in Maximo Manage. For more
information, see Incident
history.
Probability of failure analysis for predictive maintenance planning
As a reliability engineer, use the new probability of failure (PoF) analysis to estimate how
likely an asset or asset group is to fail as it ages. This analysis helps you identify high-risk
assets and make data-driven decisions about repair, refurbishment, and replacement timing. For more
information, see Probability of failure analysis.
Dynamic weights visibility on asset details page
As a Maximo Health user, you can now view dynamic weights directly on
the details page for an asset. When you view an asset's health score details, you can see the
specific weights that were applied to calculate that score, which provides greater transparency into
how asset health is determined. This enhancement helps you better understand the factors that
contribute to an asset's overall health score and makes it easier to analyze scoring results. For
more information, see Updating dynamic runtime weights during score calculation.
Deterministic ID generation and searchable names for scoring components
As a Maximo Health administrator, use the new deterministic ID
generation feature to create consistent, readable IDs for scoring groups, scores, drivers, and
factors across all environments. IDs are now automatically generated from component names using a
standardized format, which ensures that the same ID is created in development, test, and production
environments. The Assets page now supports searching for custom scores by using
these readable names instead of autogenerated IDs, which makes score selection and filtering more
intuitive when you work with multiple custom scores. This enhancement improves configuration
stability, reduces dependency on migration manager for maintaining ID consistency during migrations,
and enables analysts to reference the same readable IDs in notebook-based calculations across all
environments.
Load custom Python libraries in Health notebooks
As a data scientist, you can load custom Python utility libraries directly into Watson Studio Health notebook templates. You do not need to package libraries as
Python wheels. Use the health library (HealthLib) option to import shared
functions and add your own libraries. This approach simplifies library management across notebooks
and environments. This feature reduces manual code copying and streamlines upgrades in IBM Maximo Application Suite. For more information, see the inline documentation in the notebook.
Scoring group hierarchies for dependent asset calculations
As a Maximo Health administrator, you can now create parent-child
relationships between scoring groups that use notebooks to ensure that dependent asset scores are
calculated in the correct order. For more information, see Creating scoring group hierarchies.
Compare meter data on the Asset and location dashboard
As a reliability engineer, you can now select up to six meters and view their historical data in
both tabular and graphical formats for a chosen date range to visualize trends and assess asset
performance. Also, you can download the meter data as a CSV file for offline analysis. For more
information, see Meters.
Improved scoring performance with batch processing and multi-threading
As a Maximo Health administrator, you can now benefit from significant
performance improvements in health score calculations. The scoring engine now uses batch
processing and multi-threading architecture to calculate scores faster and more efficiently,
especially for large asset and location workloads. Optionally, you can fine-tune performance by configuring
batch size and thread count system properties to match your specific business requirements and
system resources. For more information, see Configuring internal scoring engine performance.
