What's new in Maximo Real Estate and Facilities 9.2
What's new in 
Maximo Real Estate and
Facilities 9.2
Learn more about what's new and changed in IBM® Maximo® Real Estate and Facilities
9.2.
Integration
Native S3 object storage support for file-based integrations
You can now use native S3 object storage, initially for file-based integrations in Data
Integrator and Integration Object. This support provides a robust and secure replacement for using
SFTP to work with files in the 
Maximo Real Estate and
Facilities file system. You can
configure file encryption for S3 object storage to protect files at rest in S3 buckets. File
encryption uses industry-standard algorithms (AES-256-GCM for symmetric encryption or RSA with
hybrid AES-256-GCM for asymmetric encryption) to automatically encrypt outbound files before upload
and decrypt inbound files after download. For more information, see Configuring S3 object storage.
Integration with 
Maximo Manage
Maximo Real Estate and
Facilities 9.2 introduces integration with 
Maximo Manage to synchronize location and asset data between the applications and to create work orders in 
Maximo Manage from service requests in 
Maximo Real Estate and
Facilities. The integration is mostly preconfigured and uses cluster certificates for seamless authentication, so no separate authentication configuration is required. It also includes the Manage Integration Manager application for mapping properties and buildings to sites and systems. For more information, see Maximo Manage integration overview and Integrating with Maximo Manage.
Upgrade
Application upgrade enhancements
New best practices and tooling capabilities help you follow recommended development patterns that
make upgrades simpler, faster, and less costly. By combining multiple Object Migration packages and
filtering packages to focus on custom objects, you can streamline your upgrade process and reduce
complexity. For more information, see Application upgrade best practices.
Combine multiple Object Migration import packages
You can now combine multiple Object Migration import packages into a single consolidated package.
This approach streamlines the import process and reduces the number of packages to manage during
upgrades. For more information, see Combining import packages.
Filter Object Migration packages to non-IBM objects
When you copy Object Migration packages, you can now filter to include only non-IBM labeled
objects. This option helps you focus on custom objects during upgrades and reduces package
complexity. For more information, see Copying an import or export package.
Configure Application Object Migration installation during activation
You can now configure whether the operator automatically installs the 
Maximo Real Estate and
Facilities Application OM package during deployment. Choose manual, load
only, or automatic installation options to control when and how application upgrades are applied.
This flexibility helps you manage application customizations and control the upgrade process. For
more information, see Configuring and activating 
Maximo Real Estate and
Facilities.
Platform upgrade enhancements
The User Migration Tool streamlines the process of migrating users and their license entitlements
from an existing 
IBM
TRIRIGA® environment to a 
Maximo Real Estate and
Facilities environment. The User Migration Tool is now included in the
application, simplifying the migration process. You no longer need to download and install the tool
separately from IBM Fix Central. For more information, see Migrating users and licenses.
Dynamic space planning
Floor plan markup
You can add annotations to floor plans in Dynamic space planning and Drawing manager by using
markup tools. Markup is saved separately without modifying the original drawing. You can create
multiple markups for the same floor plan and display them simultaneously. In Dynamic space planning,
markups are associated with specific scenarios. For more information, see Adding markup to floor plans.
Create space assessments from Dynamic space planning
Create space assessments directly from Dynamic space planning. The building and floor are set
from the Dynamic space planning scenario, and selected spaces are included in the assessment.
Specify an assignee and custom name. For more information, see Dynamic space planning.
Apply space assessments to Dynamic space planning scenarios
Apply people updates from space assessments to Dynamic space planning scenarios. The Space
assessment dialog displays verification and discrepancy records, showing people added or removed
from spaces. The floor plan highlights affected spaces with pins that represent these changes. For more information, see Dynamic space planning.
Lease administration
Creating a lease abstract using AI
You can now use AI to create a lease abstract by uploading up to 5 documents per lease (maximum
15 MB each, PDF, or DOCX format) for AI to populate key values. To use AI to create a lease
abstract, you must deploy AI Service. For more information, see The AI Service. After you populate values using AI, you can select
any field to view its source location from the document, then review and edit fields before you
create the draft lease abstract record. For more information about creating lease abstracts, see
Creating lease abstract records.
Month-end security lockout
System administrators can lock security groups out of the Lease Accounting module at month-end to prevent lease changes during the close period. This lockout configuration is available in the Security Groups application, where administrators select security groups to restrict and set them to read-only or no-access for a defined period. A scheduler can apply and lift the restriction automatically on a recurring schedule, eliminating manual account management. For more information, see Creating security lockouts.
Bulk Download Report
Users can download multiple real estate lease records as a single BIRT report by using the new Bulk Download Report. The Bulk Download Report is available in Contracts > Contract Set Up > Data Utilities > Bulk Download Report. For more information, see Downloading multiple real estate lease records as a single report.
Reserve app
Time format (AM/PM or 24-hour format)
To create a better user experience, users are now presented with a time picker that matches the
time format that is set in their user profiles.
Workspace UX Perceptive Apps Reserve and Workspace are greyed out if there are no meeting rooms
or workspaces in the location
Greying out the icons prevents unnecessary data entry for unavailable services. For more
information, see Creating reservations with the Room Reservation Perceptive app.
Outlook delegate synchronization
When 
Maximo Real Estate and
Facilities is integrated with Microsoft
Exchange,
delegates that are configured in 
Microsoft Outlook
 automatically sync with
Maximo Real Estate and
Facilities through the Reserve app.
Automatic room check-in with Internet of Things (IoT) occupancy sensors
If 
Maximo Real Estate and
Facilities is integrated with IBM Maximo Monitor,
the Room Reservation app and Room Panel app now support automatic check-in using Internet of Things
(IoT) occupancy sensors. For rooms that require check-in and connected to Cisco Webex devices, you
are automatically checked in when occupancy is detected. If no occupancy is detected during the
auto-cancel time, the reservation is automatically canceled.
For more information, see Creating reservations with the Room Reservation Perceptive app and Setting up the room panel Perceptive app.
Cancel and replace reservations
Reservation coordinators can now cancel rooms in existing reservations and optionally hold
replacement rooms. Replacement rooms are held for the original organizer, who receives a
notification and can accept or decline the replacement in the Reserve app. For recurring reservations,
coordinators can apply these changes to a single occurrence or the entire series. For more
information, see Creating reservations with the foundation UI.
Database
Amazon RDS for Db2® support
Customer-managed deployments on Amazon Web Services can now use Amazon RDS for Db2
as a fully managed database option. You can connect to Amazon RDS for Db2 instances, providing a
managed database deployment option when running on Red Hat OpenShift Service on AWS (ROSA). Amazon
RDS for Db2 licenses are not included in the 
Maximo Real Estate and
Facilities entitlement and
must be obtained separately through bring-your-own-license or pay-as-you-go options. For more
information about deployment, see Deploying Maximo Real Estate and Facilities in Maximo Application Suite.
Platform
IBM Semeru JDK 21 support
Maximo Real Estate and
Facilities now runs on IBM Semeru JDK 21. This
upgrade from JDK 17 provides enhanced security patches and support for the latest versions of open
source libraries.
Timezone migration tool
A timezone migration tool adjusts nonrelative date field values when the application server
timezone changes. After you configure the previous server timezone, the migration process
automatically detects timezone changes during server startup and migrates affected data by using
concurrent processing. For more information, see Timezone migration.
Modernized editable queries
Editable queries now use a modernized design that supports different field types more consistently. The updated experience aligns editable query data tables with current design patterns, helping provide a more consistent visual experience across applications.
Shared sessions between UI pods
Sessions are stored in the database and shared across UI pods. You can continue working without re-logging in if a pod fails or is recycled, as the system routes you to another available pod.
Common header
The application header provides a consistent experience across Maximo Application Suite
applications. The Help menu includes Build
information, What's new, Getting started,
Documentation, Videos, Request
enhancement, Support, and About. The
profile menu includes Edit profile, and Manage
account.
Capital projects
Currency for capital projects aligned with the primary location
The currency for capital projects is now aligned with the primary location. The primary location
is mandatory, and the Currency field is autopopulated from the primary
location. If the currency is updated from the location, a message is displayed to confirm the
change. You can edit the currency if needed. For more information, see Creating capital projects.
