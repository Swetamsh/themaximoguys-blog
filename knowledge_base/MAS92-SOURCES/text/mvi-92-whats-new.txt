What's new in Maximo Visual Inspection 9.2 IBM Maximo Application Suite
What's new in Maximo Visual Inspection 9.2
Learn more about what's new and changed in Maximo Visual Inspection 9.2.
Resource sharing
You can share data sets and models with other users to enable collaboration. When you share a resource, the selected user gains access to work with that dataset or model.
Users can collaborate on shared data, while individual permissions control the actions each user can take.
This approach improves collaboration and reduces the need to duplicate resources across multiple users.
For more information, see Sharing resources.
Model validation with ground truth data
You can use ground truth data to validate the accuracy of trained models and identify whether retraining can improve accuracy.
Model validation with ground truth data measures the accuracy of models using the following performance metrics: 
Precision
Recall
Intersection over union (IoU)
Model validation is available for image classification and object detection models.
Note: Bounding boxes are used for all object detection model evaluation.
For more information, see Model validation with ground truth data.
Updated model frameworks and architectures
Maximo Visual Inspection 9.2 modernizes the underlying model training infrastructure by transitioning to TensorFlow and PyTorch frameworks. This update removes support for legacy frameworks and introduces new model architectures that provide improved performance, accuracy, and long-term maintainability.
Key changes include:
Removal of Caffe and Darknet frameworks
Deprecation of older model architectures including SSD and GoogleNet
Standardized training experience across all model types
Enhanced security through updated libraries and regular patches
Continued support for Edge device deployment with TensorRT and CoreML conversions
These updates ensure better long-term support, faster performance, and access to the latest model architectures while maintaining compatibility with existing deployment workflows.
Enhancements to visual prompting
The visual prompting feature now includes user interface updates that improve usability and access to guidance.
These updates include:
Tooltips that provide additional context while you work
Links to product documentation and videos for in-context guidance
User interface improvements that streamline the workflow and improve consistency across screens
Visual Inspection in IBM Maximo Mobile
Quality inspectors can capture images and perform real-time inspections using trained AI models directly on iOS devices.
For more information, see Getting started for Maximo
Mobile quality inspectors.
End of support for NVIDIA Pascal GPUs 
 NVIDIA Pascal series GPUs, which includes P100, are not supported in Maximo Visual Inspection 9.2 and later. Support is also removed from earlier releases through fix packs. For more information, see May 2026 in What's new in Maximo Visual Inspection fix packs.
