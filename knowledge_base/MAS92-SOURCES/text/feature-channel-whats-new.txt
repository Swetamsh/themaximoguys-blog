What's new in the Maximo Application Suite feature channel
What's new in the Maximo Application Suite feature channel 
Learn more about what's new in the feature channel for nonproduction instances of
 Maximo Application Suite and for production instances of Maximo Application Suite as a
Service.
 Maximo Application Suite incrementally delivers updates to provide new feature
capabilities to the feature channel. As a customer-managed user, you can use the feature channel to
update your nonproduction instances to preview new features. As a SaaS user, you can use new
features in your Maximo Application Suite as a
Service environment.
You can subscribe to the feature channel by using the channel subscription method. For more
information, see Upgrading IBM Maximo Application Suite by using the channel subscription method.
Information that provides bug fixes and security updates
is available in the release notes. For more information, see Maximo Application Suite feature channel release
notes.
June 2026
 Maximo Application Suite 9.2 is available. Features that were previously delivered
in the feature channel for preview before June 2026 are now available for production. For more
information, see What's new in Maximo Application Suite 9.2.
New information will be provided when additional features are delivered for preview. 
April 2026
Application logging configuration in Application Configuration
Application Configuration now supports automatic logging configuration in preview mode. You can
control log verbosity during development and testing by configuring the
default-log-level attribute in your application XML. This feature simplifies
debugging by allowing you to switch between detailed logging for troubleshooting and minimal logging
for production testing without modifying code. For more information, see Application logging configuration.
AI assistant supports all objects
The AI assistant can now find data for any 
Maximo Manage
object and all child objects, including custom objects. By default, it can find data for assets,
service quests, work orders, asset meters and other meters, preventive maintenance, work logs,
assignments, job plans, and persons. You can enable it to find data for other objects. For more
information, see Enabling Maximo Assistant.Note: The AI configuration for
the assistant might contain an option to enable an agentic assistant. This feature is not fully
available and is not usable in the feature channel.
Data Comparison Report between Maximo and GIS with Operational Indicators
Maximo Spatial provides a report to compare data stored in
Maximo with data from ArcGIS, based on the configurations defined in the Map Manager.The report
highlights inconsistencies, missing associations, duplicate records, and attribute discrepancies
(limited to those involved in the synchronization), allowing users to analyze the information at two
levels: a high-level managerial summary and a detailed object-level view.
Create and edit line and polygon geometries on the map for Maximo objects
Maximo Spatial supports the creation and editing of line and
polygon geometries on the map for Maximo objects.By enhancing the front end to support these
additional geometry types, users gain greater flexibility and precision in managing spatial data,
unlocking new use cases, and improving overall usability.
March 2026
Group access to object structures
To align and centralize security configuration for users, you can give groups access to object
structures. The Object structures tab originally in the Security
groups (Manage) application in 
Maximo Manage is now
available in suite security. You can specify access to object structures in Security groups by
selecting Suite > Access and
usage > Security groups. For more information, see
Object structures and security groups in Maximo Application Suite 9.2.

February 2026
Storm search function in 
IBM Outage
Prediction
In the Storm search page, the following function is now available for each
storm event result. 
Outages map view with outage levels.
The outages data represents actual historical outage data.
The filters that you use in the Storm search page apply to the number of
storm event results that display. Now when you open a storm event result, the related storm event
data is not limited by the filters, instead you see all the storm data for that storm event.
Configuring system event emails
You can configure system event emails, such as welcome or password reset email, that are sent to
users by using the Communications template application. This configuration process changed to
streamline the management of email notifications for user management operations. For more
information, see Configuring system event emails for Maximo Manage deployments in Maximo Application Suite 9.2
SMTP OAuth2 Authentication for outbound emails
You can configure OAuth2 credentials for the SMTP server for outbound emails in Maximo Application Suite by using SMTP configuration. For more information, see Simple Mail Transfer Protocol configuration. 
Adoption metrics
Adoption metrics track how users engage with product features in Maximo Application Suite and Maximo Application Suite as a
Service. These metrics can help IBM
understand feature usage, user engagement, and product adoption trends to help improve the product
experience. For more information, see Adoption metrics.
Group access to sites
To align and centralize security management of users, you can give groups access to records and
data in all sites or specify access to individual sites. The Sites tab
originally in the Security groups (Manage) application in 
Maximo Manage is now available in suite security. You can specify access
to sites in Security groups by selecting Suite > Access
and usage > Security groups.
Support for SAP Cloud Platform Integration (SAP CPI)
 Maximo Connector for SAP Applications supports a new middleware method. The new SAP
connector is developed using the latest SAP-recommended middleware, SAP Cloud Platform Integration.
This ensures better compatibility, improved performance, and seamless integration with modern SAP
systems and cloud-based applications.
For more information, refer to Configuring Maximo Connector for SAP Applications with SAP
Integration Suite (SAP CPI).
Customizable action buttons in Identify tool
Maximo Spatial supports the addition of custom action buttons in
the Identify tool.Configure custom action buttons in the Identify tool to support specific user
workflow. This enhancement enables organizations to tailor the map interface to their unique
business processes and improve user productivity.
January 2026
Additional resources in Maximo Application Suite as a
Service
As a SaaS administrator, you can now request additional resources that include components or
configurations that might be needed after Maximo Application Suite as a
Service is installed. These
resources support specific features, integrations, or performance requirements, such as increasing
instance capacity, or changing GPU capacity or GPU models. If your environment requires more
capacity, contact your IBM representative to review your usage and recommend adjustments. You can
monitor your additional resource usage and AppPoint cost in the Usage dashboard by selecting
Suite > Administration > Usage.
Configuring self-registration form
You can configure the login page to include up to three extra fields for self-registration by
updating the self-registration configmap. For more information, see Adding fields to the self-registration form
Arabic and Hebrew language support
Support for Arabic and Hebrew is available for applications that are built on the Maximo Application Framework. For more information, see Arabic and Hebrew language support.
Use gpt-oss-120b model for some AI features
You can now use the gpt-oss-120b model for mcc, pcc, fmea, and nl2oslc model templates. The
nl2oslc model template is for the AI assistant. If you are already using a Granite model and need to
move to gpt-oss-120b, see Changing to gpt-oss-120b models.IBM Granite 3.2 8b
Instruct is deprecated as of 25 November 2025. For more information, see Foundation model lifecycle.

UI changes in 
IBM Outage
Prediction

JSON Web Token expiration
Previously, the JSON Web Token had a short expiry time and required frequent regeneration. You
can now generate the JSON Web Token greater than 90 days or without any expiration time. For
example, you can specify the mas-jwt-expiry-duration header name as
P100Y for a 100-year duration or NEVER to never expire. for more
information, see Configuring Maximo Application Suite to synchronize user and groups with SCIM 2.0
Icon in header to launch AI assistant
You can now launch the AI assistant by clicking an icon in the page header in 
Maximo Manage, Maximo Health, Operational
Dashboard, and asset dashboards.
AI-generated insights in Maximo Health
The Insights card on the Asset dashboard now delivers AI-powered analysis
of your asset's performance. Get visibility into key trends, potential risks, and upcoming
maintenance requirements. For more information, see Asset dashboard and AI-generated insights.

IBM Outage
Prediction
